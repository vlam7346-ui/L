ANY FRUIT — WEBSITE PACKAGE (FLAT VERSION)

This version places all files in the SAME GitHub repository folder, so images and logo paths work with a flat upload.

Files: index.html, style.css, script.js, anyfruit-logo.jpg, photo-01.jpg through photo-23.jpg.

ANDROID / GITHUB UPLOAD
1. Download and extract this ZIP on your phone.
2. Open repository https://github.com/vlam7346-ui/L
3. Back up the existing site before replacing files.
4. Add file -> Upload files. Select index.html, style.css, script.js, anyfruit-logo.jpg and all photo-*.jpg files from the extracted folder. Do not upload the enclosing folder itself.
5. Commit changes to main. Keep the existing CNAME file; do not delete it.
6. Wait a few minutes, then open https://anhnhuy.com in Chrome and refresh.

IMPORTANT: Upload all the files listed above together into the same location as the repository's existing index.html. Keep CNAME. This package does not itself publish the site or change domain settings.
